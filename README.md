# INTER-PROC Kitchens

Static portfolio website for INTER-PROC, a kitchen and cabinetry business in Uganda.

## Website source

The production-ready site is a self-contained `index.html` containing its CSS, JavaScript, and ten embedded photographs. Upload `index.html` to the root of this repository before connecting Vercel.

## Vercel

Import this GitHub repository. Use the **Other** framework preset, repository root as the root directory, and no build command. The site entry point is `index.html`.
